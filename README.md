AI Resume Analyzer

AI-powered Resume Analyzer built using Flask, LangChain, Ollama and Llama 3.

Features

* Upload Resume PDF
* Paste Job Description
* Analyze Resume using AI
* Match Score Generation
* Missing Skills Detection
* Improvement Suggestions

Tech Stack

Frontend

* HTML
* CSS
* JavaScript

Backend

* Flask
* Python

AI

* LangChain
* Ollama
* Llama 3

Run the Project

Install dependencies:

pip install -r requirements.txt

Run:

python3 app.py
